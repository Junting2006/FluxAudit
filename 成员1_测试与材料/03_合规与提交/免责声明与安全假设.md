### 完整版免责声明（提交材料用）

1. **性质**：FluxAudit（流审）是 AI 辅助的链上尽调与审计工具。其输出为**辅助性诊断结论**，旨在帮助用户复核信息、识别风险信号，**不构成**财务、投资、法律或合规意见。
2. **数据基础**：本报告基于公开链上数据（测试网 RPC、Etherscan 等公开接口）、用户提供的文档，以及合成或已脱敏的演示数据。数据可能存在延迟、误差或不完整。
3. **AI 局限**：系统由大语言模型驱动，存在幻觉与误判风险。每条结论均标注证据来源，但证据本身可能不完整；**高风险结论必须经人工复核后方可作为决策依据**。
4. **不构成建议**：任何评分、评级与结论均不代表对任何项目、资产或交易的推荐、背书或否定。
5. **测试网性质**：链上存证锚定于 Sepolia 测试网，用于演示可验证机制，不涉及真实资产与真实资金。

## 二、安全假设（答辩口径）

1. **执行环境假设**：AI 推理在本地可信执行环境运行，链上仅存证哈希——上链数据不泄露报告原文内容。
2. **密码学承诺**：采用 keccak256 哈希链 + Merkle Root + 测试网锚定，实现"篡改可发现"；**这是完整性承诺，不是 zkML 隐私证明**，当前版本不含零知识证明。
3. **不声称"完全去信任"**：哈希计算、锚定交易与验证页的实现可信度受部署代码与前端环境约束，我们如实披露人工确认点。
4. **密钥管理**：私钥、助记词、API Key 不进入仓库、录屏、PPT 与公开材料；提交前执行 secret scan。

## 三、局限性说明（诚实披露，答辩必背）

| 局限 | 说明 |
|---|---|
| 数据范围 | 演示阶段仅 Sepolia 测试网与合成数据，未接主网实时索引 |
| 模型误差 | AI 可能误判、漏判、幻觉；结论须人工复核 |
| 单链支持 | 当前仅支持 EVM 兼容链（Sepolia），多链在规划中 |
| 非实时监控 | 审计为"按任务执行"，非持续性风控监控 |
| 非 zkML | 可验证机制为哈希承诺 + 链上锚定，非零知识证明 |
| 演示披露 | 现场如实说明哪些步骤自主运行、哪些人工触发/确认、是否使用预录视频或 Mock 数据 |
